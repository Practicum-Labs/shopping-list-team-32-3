# Список покупок — дизайн и экраны

> Требования к **дизайну/проектированию UI**: дизайн-система, палитра, темизация,
> UI-паттерны, а также описание всех экранов, состояний и переходов.
> Источник истины по UI — прототип Figma. Функциональные требования с приоритетами —
> в [functional-requirements.md](functional-requirements.md); архитектура — в
> [architecture.md](architecture.md).

**Прототип:** [Figma UI-kit](https://figma.com/design/n84usOH28EjTrPXrfCzM3q/Практикум-ОП-Список-покупок)
**Дизайн-система:** Material Design 3 · светлая и тёмная темы (наборы экранов идентичны).
**Модальные окна** реализованы как **bottom sheet** (модальная шторка снизу, во всю
ширину, со scrim-затемнением) — подтверждено макетами Figma (фреймы 412×892 со Scrim).

## 2. Темизация (Compose + Material 3)

Приложение поддерживает светлую и тёмную темы по Material Design 3 (NFR-01).

**Реализация — средствами Jetpack Compose, без legacy XML-темизации:**
- Цвета описываются как `ColorScheme` через `lightColorScheme()` и `darkColorScheme()`
  на основе токенов из Figma (см. §1). Палитра — в `core/ui/theme/Color.kt`.
- Тема приложения — `MaterialTheme(colorScheme = …, typography = …)` в
  `core/ui/theme/Theme.kt`; типографика — в `Type.kt`.
- Выбор светлой/тёмной схемы — по системной теме через `isSystemInDarkTheme()`.
- Цвета **не хардкодятся** в composable: используются `MaterialTheme.colorScheme.*`.

**Критерии приёмки:**
- Светлая и тёмная схемы заданы через `ColorScheme` (а не `res/values-night` + theme `attrs`).
- Все экраны корректно читаемы в обеих темах; переключение следует системной теме.

## 3. UI-паттерны

- Иконки интерфейса — из набора Material Symbols (add, edit, delete, content_copy,
  sort_by_alpha, drag_handle, swap_vert и др.).
- Иконки для списков (FR-MAIN-07) — тематический набор Material Symbols (cake,
  celebration, child_care, medication, microwave, self_care, palette, apparel,
  import_contacts, luggage, photo_camera, directions_car и др.).
- **Купленный товар** отображается **зачёркнутым** текстом.
- Главное действие добавления (списка / товара) — кнопка **FAB**.
- Модальные диалоги/меню реализуются как **bottom sheet** (шторка снизу) со scrim.
  Шторки закрываются свайпом вниз, тапом по scrim или кнопкой «Отмена».

## 4. Обзор экранов

Логически приложение состоит из **трёх экранов**; всё остальное — их состояния и
модальные шторки.

| # | Экран | Назначение |
|---|---|---|
| 1 | **Онбординг** | Приветствие при первом запуске |
| 2 | **Мои списки** (главный) | Перечень списков покупок, управление ими, поиск |
| 3 | **Список** (детали) | Товары внутри выбранного списка, управление товарами |

### Карта экранов и навигация

```
                 первый запуск
   [Онбординг] ───────────────▶ [Мои списки]
                                     │
        ┌────────────────────────────┼─────────────────────────────┐
        │ (FAB +)                     │ (иконка поиска)              │ (тап по списку)
        ▼                             ▼                              ▼
  ⤵ шторка «Добавление          режим поиска                   [Список (детали)]
     списка»                  (найдено / не найдено)                 │
                                                                      │
   действия над списком (свайп / меню):              действия над товарами:
     • Переименовать  ⤵ шторка                          • Добавить товар  ⤵ шторка
     • Удалить        ⤵ подтверждение                       (имя+подсказки, кол-во, ед.)
     • Дублировать                                       • Отметить куплено (зачёркивание)
     • Сменить иконку ⤵ шторка с иконками               • Редактировать   ⤵ шторка
                                                         • Контекстное меню ⤵ шторка:
                                                             Переименовать / Удалить /
                                                             Очистить купленные
                                                         • Сортировка: по алфавиту /
                                                             вручную (drag & drop)
                                                         • Удалить все   ⤵ подтверждение
```

Переход назад со «Списка» возвращает на «Мои списки».

## 5. Экран: Онбординг

**Назначение:** поприветствовать пользователя при первом запуске и кратко объяснить суть.

**Что на экране** (Figma: `Onboard`):
- Иллюстрация (`Illustration_Main screen`) и логотип приложения.
- Заголовок: **«Добро пожаловать в Список покупок!»**
- Подзаголовок: **«Создавайте списки, добавляйте товары, отмечайте, что уже куплено»**.
- Элемент навигации (кнопка перехода далее).

**Как работает:** показывается один раз при первом запуске; по нажатию кнопки перехода
открывается экран «Мои списки». При последующих запусках экран пропускается.
Требование — FR-ONB-01.

## 6. Экран: Мои списки (главный)

**Назначение:** показать все списки покупок и дать ими управлять.

### Элементы
- **Карточка списка** = иконка списка + название (напр. «Продукты», «Для дома»,
  «Подарки к Новому году»). Тап открывает экран «Список».
- **FAB** (плавающая кнопка «+») — создать новый список.
- **Иконка поиска** в верхней панели — перейти в режим поиска по спискам.
- Верхняя панель приложения (TopAppBar).

### Состояния
| Состояние | Figma | Описание |
|---|---|---|
| Пустой | `lists are empty` | Списков нет — заглушка с предложением создать первый |
| Со списками | `Main`, `Main-lists` | Перечень карточек списков |
| Скролл | `scrollable lists`, `shopping lists` | Много списков — вертикальная прокрутка |
| После переименования | `Main-renamed list` | Карточка с обновлённым названием |
| После смены иконки | `Main- icon has been changed` | Карточка с новой иконкой |

### Действия и шторки

**Создать список** (`Main-List add`, `…add input text`, `…add label text`,
`…add text filled`): по FAB открывается шторка **«Добавление списка»** с полем
«Название списка» (placeholder «Новый список») и кнопками **«Отмена» / «Создать»**.
По «Создать» список добавляется в перечень.

**Переименовать список** (`Main-list renaming`, `Main-text input`, `Main-text filled`):
шторка **«Переименование списка»** с текущим названием в поле и кнопкой
**«Переименовать»**.

**Удалить список** (`Main-delete list`, `Main-swipe delete modal`): показывается
**подтверждение** (шторка) с кнопками **«Отмена» / «Удалить»**.

**Сменить иконку списка** (`Main- change the icon modal`): шторка с **сеткой иконок**
(набор Material Symbols: cake, celebration, child_care, medication, microwave, self_care,
palette, apparel, import_contacts, luggage, photo_camera, directions_car и др.). Выбор
иконки применяется к списку (`Main- icon has been changed`).

**Дублировать список** (`Main-swipe to duplicate`): создаётся копия списка со всеми
товарами (по принятому решению — с **снятыми** отметками «куплено»).

**Удалить все** (`Main-delete all modal`): подтверждение массового удаления.

**Свайп-действия** (`Main-list swipe`, `Main-list swipe to end`, `Main-swipe editing`):
горизонтальный свайп карточки открывает быстрые действия (редактировать/удалить/
дублировать).

### Режим поиска
- **Поиск** (`Main-Search`): поле ввода + клавиатура; список фильтруется по названию.
- **Найдено** (`Main-search found`): показаны совпавшие списки.
- **Не найдено** (`Main-search not found`): заглушка «ничего не найдено»
  (иллюстрация `Illustration_Search screen`).

## 7. Экран: Список (детали)

**Назначение:** показать товары выбранного списка и управлять ими.

### Элементы
- **Строка товара** = чекбокс + имя товара + вспомогательный текст «количество единица»
  (напр. «1 л», «10 шт», «1 уп»). **Купленный товар отображается зачёркнутым.**
- Верхняя панель с названием списка и кнопкой меню (⋮).
- **FAB** «+» — добавить товар.

### Состояния
| Состояние | Figma | Описание |
|---|---|---|
| Пустой | — | Товаров нет — заглушка с предложением добавить товар |
| С товарами | `list - add items`, `Item added to the list` | Перечень товаров |
| Отсортирован | `shopping list - sorted` | После применения сортировки |
| После перемещения | `shopping list - moved` | После ручной сортировки |

### Действия и шторки

**Добавить товар** (`list - add items`, `list - product input`, `list - quantity input`,
`list - enter unit of measure`, `list - unit selected`, `list - when all is entered`):
шторка с полями:
- **Товар** (имя) — при вводе показываются **автоподсказки** ранее введённых имён
  (напр. «Мол» → «Кокосовое молоко», «Молоко», «Соевое молоко», «Сухое молоко»);
  тап по подсказке подставляет имя.
- **Количество** — числовой ввод.
- **Единицы** — выбор из набора: **л, мл, уп, пач, шт, кг, г**.
После заполнения товар добавляется в список (`Item added to the list`).

**Редактировать товар** (`list - edit product`): шторка с предзаполненными полями
(имя / количество / единицы) для изменения.

**Отметить купленным** (`marking the purchased item on a list`): тап по чекбоксу —
товар становится зачёркнутым; повторный тап снимает отметку.

**Контекстное меню списка** (`shopping list - menu`): шторка-меню с пунктами
**«Переименовать» / «Удалить» / «Очистить купленные»**.

**Очистить купленные** (`clear out purchased items`): подтверждение
**«Удалить все купленные товары?»** — удаляет из списка все отмеченные товары.

**Удалить все товары** (`shopping list - delete all items in the list`): подтверждение
массового удаления товаров.

**Сортировка:**
- **По алфавиту** (`shopping list - sort alphabetically`) — выбирается в меню.
- **Вручную / drag & drop** (`shopping list - manual sorting`,
  `…manually dragging and dropping a list`, `…moving a row to the top of the list`,
  `…moved`) — перетаскивание строк за «ручку», порядок сохраняется.

**Свайп по товару** (`shopping list - swipe an item in the list`): горизонтальный свайп
открывает действия редактировать/удалить.
