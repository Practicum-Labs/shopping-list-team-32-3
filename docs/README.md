# Документация проекта «Список покупок»

Документация разделена на **требования к структуре/проектированию** и **требования
к работе приложения**.

| Документ                                                 | Содержание                                                                                                                                                                                                          |
|----------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [architecture.md](architecture.md)                       | **Структура и проектирование.** Технологический стек, MVI, слои `data/domain/ui`, раскладка пакетов (package by feature), DI (Koin), навигация (type-safe), статический анализ (detekt), релизная сборка и подпись. |
| [design.md](design.md)                                   | **Дизайн и экраны.** Дизайн-система Material 3, палитра/токены, темизация под Compose, UI-паттерны (FAB, bottom sheet, зачёркивание), описание всех экранов, состояний и переходов.                                 |
| [functional-requirements.md](functional-requirements.md) | **Требования к работе приложения.** Функциональные требования (FR-*), поведенческие NFR, карта навигации, принятые решения, сводный чек-лист.                                                                       |
| [team.md](team.md)                                       | **Команда.** Участники и задачи.    |

**Прототип / источник истины по UI:** [Figma UI-kit](https://figma.com/design/n84usOH28EjTrPXrfCzM3q/Практикум-ОП-Список-покупок).
